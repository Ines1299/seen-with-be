# CineCircle Backend

Backend API for CineCircle — an app for discovering film screenings/events, marking yourself as going/interested, and seeing who else is going.

## Stack

- Node.js
- Express
- TypeScript
- tsx (dev runtime)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Set up environment variables

Copy `.env.example` to `.env` and fill in values:

```bash
cp .env.example .env
```

### 3. Run the dev server

```bash
npm run dev
```

Server runs on `http://localhost:3000` by default.
